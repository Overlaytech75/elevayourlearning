# Eleva - Elevate your learning.

**Eleva** is a modern, AI-powered personal operating system specifically designed for students. It goes beyond a simple task manager or note-taking app by integrating your academic life, finances, productivity, goals, and personal growth into one intelligent, unified dashboard.

---

## 🌟 Core Features

### 🎓 Academic Management
- **Semester & Course Tracking**: Manage semesters, terms, courses, and units seamlessly.
- **Assessment Tracker**: Keep track of upcoming assignments, due dates, weights, progress, grades, and feedback.
- **Smart Timeline**: A visual timeline of your academic journey from today to the end of the semester.

### 💰 Finance & Investment Tracker
- **Income & Expense Tracking**: Monitor your salary, scholarships, and daily expenses with categorized insights.
- **Goal-Oriented Savings**: Set and track savings goals for emergencies, travel, or big purchases.
- **Investment Journal**: Track your stocks, crypto, and managed funds with ROI and portfolio allocation charts.

### ⚡ Productivity & Focus
- **Task Management**: Recurring tasks, Pomodoro timers, and Deep Work session tracking.
- **Habit Tracking**: Monitor sleep, exercise, reading, and study habits with consistency graphs.
- **Goal System**: Set structured milestones for academic, financial, career, and personal goals.

### 🤖 AI-Powered Mentorship
- **Study Planner**: Automatically generates daily and weekly study schedules based on your deadlines and availability.
- **Smart Recommendations**: Receive proactive insights like "You are falling behind in Networking" or "Start Assignment 2 today."
- **AI Mentor & Coach**: Ask questions about your study progress, finances, and priorities, getting answers tailored to your exact data.

### 📓 Unified Notes & Knowledge Base
- **Rich Markdown Notes**: Support for code blocks, images, and attachments.
- **AI Integration**: Auto-generate summaries, flashcards, and quizzes directly from your notes.

---

## 🚀 Getting Started

To run Eleva locally, you'll need Node.js and npm installed.

```bash
# Clone the repository
git clone https://github.com/Overlaytech75/elevayourlearning.git

# Navigate to the project directory
cd elevayourlearning

# Install dependencies
npm install

# Start the development server
npm run dev
```
